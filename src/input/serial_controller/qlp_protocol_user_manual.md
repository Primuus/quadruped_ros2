# QLP 串行通信协议用户手册

## 1. 协议帧格式

| 字段 | 长度（Byte） | 说明 |
|---|---:|---|
| `SOF` | 1 | 帧头，固定为 `0x23`（字符 `#`） |
| `ADDR` | 1 | 目标设备地址 |
| `SRC` | 1 | 源设备地址 |
| `FC` | 1 | 功能码 |
| `LEN` | 2 | 数据区长度，小端格式，表示 `DATA` 字节数 |
| `DATA` | N | 数据区，内容由 `FC` 定义 |
| `CRC16` | 2 | CRC-16/MODBUS，小端格式，校验范围：`ADDR` 到 `DATA` |

| 0 | 0 | 1 | 0 | 0 | 0 | 1 | 1 | `0x23` |

### 2.3 `FC`

| Bit7 | Bit6 | Bit5 | Bit4 | Bit3 | Bit2 | Bit1 | Bit0 | 范围 | 说明 |
|---:|---:|---:|---:|---:|---:|---:|---:|---|---|
| 0 | X | X | X | X | X | X | X | `0x00`~`0x7F` | 控制/配置类 |
| 1 | X | X | X | X | X | X | X | `0x80`~`0xFF` | 状态/上报类 |

#### 功能码定义

| `FC` | 名称 | 说明 |
|---|---|---|
| `0x01` | 通用控制 | 单设备控制命令 |
| `0x02` | 通用参数写入 | 参数写入命令 |
| `0x03` | 通用参数读取 | 参数读取命令 |
| `0x81` | 通用状态上报 | 单设备状态上报 |
| `0x90` | 遥控器摇杆上报 | `mode + 4个float + key` |
| `0x91` | 陀螺仪上报 | 姿态角/角速度等数据 |
| `0xA0` | 电机状态上报 | 电机位置、速度、电流等 |

### 2.4 `LEN`

| Byte1 | Byte0 | 说明 |
|---:|---:|---|
| 高字节 | 低字节 | 小端格式，`LEN = Byte0 + (Byte1 << 8)` |

### 2.5 `CRC16`

| Byte1 | Byte0 | 说明 |
|---:|---:|---|
| 高字节 | 低字节 | CRC-16/MODBUS，小端发送，校验范围：`ADDR..DATA` |

## 4. `DATA` 使用规则

| 项目 | 规定 |
|---|---|
| 字节序 | 多字节整数、小数统一使用小端格式 |
| 浮点格式 | `float32`，IEEE-754 单精度，4 字节 |
| 数据类型区分 | 不在协议中单独标识类型，`DATA` 的字段顺序和类型由 `FC` 唯一决定 |
| 混合数据 | 同一帧内允许同时包含整数和浮点，发送与接收双方必须对同一 `FC` 使用相同的数据布局 |

## 5. 遥控器上报数据定义

### 5.1 帧头定义

| 项目 | 取值 |
|---|---|
| `ADDR` | `0x11`（主控板） |
| `SRC` | `0x31`（遥控器） |
| `FC` | `0x90` |
| `LEN` | `18` |

### 5.2 `DATA` 字段定义

| 偏移 | 长度（Byte） | 名称 | 类型 | 说明 |
|---:|---:|---|---|---|
| 0 | 1 | `mode` | `uint8` | 模式键值 |
| 1 | 4 | `joy_lx` | `float32` | 左摇杆 X |
| 5 | 4 | `joy_ly` | `float32` | 左摇杆 Y |
| 9 | 4 | `joy_rx` | `float32` | 右摇杆 X |
| 13 | 4 | `joy_ry` | `float32` | 右摇杆 Y |
| 17 | 1 | `key` | `uint8` | 按键值 |

## 6. 物理链路说明

| 项目 | 规定 |
|---|---|
| 支持链路 | UART / RS485 / CAN |
| 地址含义 | 无论使用 CAN 还是 485，`ADDR` / `SRC` 定义保持一致 |
| 移植原则 | 物理层只负责收发字节流，协议层统一按本手册解析 |
